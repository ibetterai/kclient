# AGENTS.md — ibetterai/kclient

i18n-enabled fork of linuxserver/kclient (KasmVNC sidebar client), consumed by
ibetterai/terminal-streaming's browser-vnc Docker image via pinned `git clone` overlay.

Read `CLAUDE.md` first — it holds the project conventions, documentation map, and
architecture pointers. Org-wide doctrine and the standards index live in
[ibetterai/ibetter-standards](https://github.com/ibetterai/ibetter-standards).

## Cross-repo standards
Any PR that creates or changes a cross-repo standard, dependency, workflow, or
operational procedure MUST include the corresponding update to
ibetterai/ibetter-standards in the same PR or a linked PR (see
standards/cross-repo-changes.md there). Org doctrine and the standards index
live in that repo.
